## Mackit 1.0.11

Settings now reports the app's own permissions, and the cleanup covers fourteen more language ecosystems.

- **Settings → General reports the app's own permissions.** Full Disk Access, the Finder and Terminal automation consents and administrator authorization each get a row with their live status, what the permission unlocks, and a button that opens the exact settings row. The statuses re-probe whenever the app returns to the foreground, so a grant made while Mackit sat in the background shows up without a relaunch.
- **Cache cleanup for fourteen more language ecosystems.** Ruby, PHP, .NET, Scala, Haskell, Clojure, Elixir/Erlang, Lua, Julia, OCaml, Zig, Nim, Crystal and Perl each join the scan as their own category with its brand mark — 30 scan rules and 5 command-line rules on top of the eight ecosystems already covered. Every path was verified against the installed tool or its official source rather than assumed, which caught the two places the obvious guess is wrong: modern cabal uses the XDG layout (`~/.cache/cabal`, `~/.local/state/cabal`) with `~/.cabal` only as a legacy fallback, and Zig and Crystal both honor `XDG_CACHE_HOME` ahead of their `~/.cache` defaults.
- **The unreadable-folders notice appears only when it can help.** With Full Disk Access in place, the large-file analysis ignores the folders the walk still could not read — a grant cannot unlock a system-protected or locked folder, so the notice only offered a permission you already have.
- **The uninstall page drops last-opened times.** Those dates are Spotlight metadata that exists only while the index serves the app's volume, so an unindexed machine read "never launched" for every third-party app; the dates, the guess and the notice are gone. Every row keeps its icon, version, size and leftover-file count.
- **Settings moves to the sidebar's foot.** The Settings row leaves the bottom of the list and becomes a capsule beside the brand and share capsules; the menu bar item, the keyboard shortcut and the tray agent's entry keep working unchanged.

### Under the hood

- The Full Disk Access probe now tests the filesystem gate itself instead of asking the Spotlight index for Mackit's own last-used date, which cannot tell a missing grant from an index that is not running — with indexing off the lookup is nil either way, so the permissions page reported "not granted" on a machine that had already granted it. The probe opens one of the folders TCC hides without the grant; measured on macOS 27, every candidate fails with EPERM while `~/Library/Calendars` and `~/Library/Reminders` open normally, so the gate is the permission and not the folder's mode.
- Risk follows what deleting each location costs: package stores and toolchains that re-download wholesale — user gems, NuGet global packages, sbt boot, cabal's store, stack's toolchains, LuaRocks, Nimble — are review-level, while pure caches stay safe. Hex's glob targets only its cache files, so the API credentials in `hex.config` are never offered.
- The home-prefix abbreviation and the Documents / Desktop / Downloads skip set each lived in two places that had drifted apart; both now share one cached helper (`Formatters.abbreviateHome`, `FileSystem.protectedHomePaths`), with the moved logic pinned by new unit tests.
- 619 tests (+21 since 1.0.10) cover the permission probes, the new ecosystems' path contracts and the moved helpers.
