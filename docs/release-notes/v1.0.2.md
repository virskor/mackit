## Mackit 1.0.2

The About section now points at the official website and the GitHub repository.

- **About links**: the website entry opens the official site (<https://www.mingcui.cn/mackit/>), and a new GitHub repository link (<https://github.com/virskor/mackit>) sits beside it. Both labels are localized in Simplified Chinese, English and Traditional Chinese.
- **Universal binary**: one download covers both Apple silicon (arm64) and Intel (x86_64) Macs, macOS 14 or later.
- **Signed and notarized**: Developer ID signature with the notarization ticket stapled — double-click to install, no Gatekeeper warning.
- **In-app updates**: 1.0.x users get this release through Sparkle, no browser re-download needed.

### Under the hood

- `AGENTS.md` records the contributor workflow: build and test commands, code conventions, and the English-first rule for development artifacts.
- `docs/RELEASE.md` documents the GitHub Releases hosting layout (the four assets every release must carry, and why `MACKIT_DOWNLOAD_URL_PREFIX` must point at the release's own tag).
