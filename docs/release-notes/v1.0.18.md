## Mackit 1.0.18

A light / dark / follow-the-system appearance picker in Settings, a duplicate-file finder and cleaner, and a Java category for the JVM build caches.

- **An appearance picker in Settings chooses light, dark or following the system** — it applies to the main window, the tray panel and every sheet immediately, without a restart.
- **Gradle, Maven and JDK caches now sit in a Java category of their own** — the Android category keeps the SDK, Android Studio and Kotlin/Native caches.
- **A duplicate-file tool finds content that exists more than once** — it scans your home folder, groups files with byte-identical content, marks the copy it suggests keeping, and moves only what you check to the Trash.

### Under the hood

- Every screen's colors, type sizes, corner radii and shadows now come from one `Theme` layer instead of values written into each view, which is what let the appearance choice reach the whole interface from a single modifier.
- Duplicate groups are proven by full-content SHA-256 digests after size and head-digest prefiltering, and deletion rides the shared clean engine's Trash, protected-path and vnode re-checks.
- Rules keep their old ignore-list entries across the category move: `RulesCatalog.renamedRuleIDs` translates the Android-era ids when settings load, so a rule you had ignored stays ignored.
