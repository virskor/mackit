## Mackit 1.0.19

Size sorting in the duplicate-file tool.

- **The duplicate-file tool can sort its groups by size** — a menu beside the threshold orders them largest-first (the new default) or smallest-first, and re-orders the groups already found while a scan is still running.

### Under the hood

- The size order is computed when the list is read rather than written into the scan results, so a sort change applies mid-scan without restarting it, and the duplicate and large-file pages share one `SortMenuPill` control.
