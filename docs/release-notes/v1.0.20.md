## Mackit 1.0.20

A right-click context menu on the tray icon, and the desktop floating stats window is gone.

- **The tray icon now has a right-click context menu** — one native menu carries the main window and settings entries, every tool page, the CPU / memory / temperature display switches with their current states, check for updates, about and quit, without opening the panel first.
- **The desktop floating stats window is gone** — CPU / memory / temperature remain in the menu-bar item and the tray panel, and the settings page and tray menu no longer offer the overlay.

### Under the hood

- The status item is an AppKit-owned `NSStatusItem` (`TrayStatusController`) rather than SwiftUI's `MenuBarExtra` — which cannot tell a left click from a right click — so left-click opens the panel popover and right-click pops the menu, and the panel's sizing and dismissal are explicit popover methods instead of matches against SwiftUI's internal window class name.
- The menu's display switches read and write the shared settings store in both directions, so the tray menu, the panel and the settings page always show the same state, and check-for-updates forwards to the main app when the up-to-date feed allows it.
- The overlay's removal drops its controller, settings toggle, tray menu row, shared-settings keys, catalog entries, tests and the three theme tokens only it used.
- The About item feeds the standard panel the product name and icon explicitly: the agent bundle's own identity reads as "Mackit Agent", and the icns now ships inside the agent bundle for the panel to draw.
