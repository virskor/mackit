## Mackit 1.0.1

A release-pipeline verification build: the first end-to-end test of signing, notarization, DMG installation and in-app auto-update.

- The update feed now lives on GitHub Releases (`https://github.com/virskor/mackit/releases/latest/download/appcast.xml`), anonymously fetchable once the repo is public
- Update archives and the appcast ship with every Release, so 1.0.0 users can upgrade straight to 1.0.1 from inside the app
- Developer ID signing + notarization + stapling all pass; download and double-click to install
- Added maintainer-facing release and hosting notes (`docs/RELEASE.md`)
