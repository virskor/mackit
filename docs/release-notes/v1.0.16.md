## Mackit 1.0.16

The monitoring surfaces now show the CPU's real temperature, and the scans behind every page got faster.

- **The temperature is shown in degrees** — read through the SMC and shown in whole degrees on the menu bar, in the panel and on the desktop stats, orange from 70°C up, with the thermal-state word as the fallback when no sensor answers.
- **Scans finish sooner** — the project-junk walk, Downloads scan, app-residue probe and Application Support index read each directory in one bulk call instead of stat'ing every entry, the shared `~/Library` listings and language subtags are resolved once per scan, and the merge dedup index is maintained incrementally instead of rebuilt per batch.
- **The result pages render lighter** — the general cleanup page's hundreds of sub-rows render lazily, large-file rows cache their size text, and the treemap skips its re-sort when children already arrive largest-first.

### Under the hood

- The SMC read opens one connection per sample and closes it on the way out, and its selection, filtering and decoding are a pure function over an injected key reader, so the logic is unit-tested without an SMC.
- The kext record's offsets are named constants, because a struct-derived `data8` lands in the record's padding, where the kext reads a zero command and every call fails.
- The merge's dedup index answers "is any already-listed entry inside this path?" by inverting it: the strict ancestors of every listed path are collected as items are appended, and the query is one set lookup.
