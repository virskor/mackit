## Mackit 1.0.0

The first stable release.

- **Cache scanning**: one click scans 50+ kinds of developer caches (Go / Node / Flutter / Rust / Python / CocoaPods / Xcode / Gradle and more), streams results as it goes, and lets you clean item by item, with a risk level on every item
- **App uninstall**: lists installed apps and their leftover files under `~/Library`, so you can uninstall an app together with its leftovers; running apps are refused
- **Project build artifacts**: scans custom directories for rebuildable folders such as `node_modules`, `build`, `Pods`, `DerivedData`, `target` and `.venv`
- **Menu bar panel**: CPU / memory / temperature monitoring, per-app memory ranking with one-tap release, and free disk space
- **Localization**: Simplified Chinese / English / Traditional Chinese, following the system language
