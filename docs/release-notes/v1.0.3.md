## Mackit 1.0.3

A second cleanup feature aimed at everyday Mac users, plus a brand pass across the whole app.

- **General cleanup module**: a dedicated page directly under "All Items", with one big cleanable-files number and rule rows grouped into system junk and browsing junk. Each row shows its size and safety level, rows arrive pre-checked up to "recommended", caution rows (Trash, Downloads installers, iOS backups) stay unchecked until you opt in, and cleaning still goes through the confirmation sheet.
- **New coverage under the general module**: browser caches (Chrome family, Chromium, Edge, Brave, Arc, Opera, Firefox, QQ Browser), useless language files inside app bundles (only whole `.lproj` directories are ever removed, keeping code signatures valid), and installers and archives in `~/Downloads`.
- **Sweep app caches without uninstalling**: an app's leftovers are split into regenerable junk (caches, HTTP storages, WebKit data), which belongs to the general module, while data (preferences, Application Support, containers, cookies) stays with the app in the uninstall flow, where deleting it is your explicit intent.
- **Remembered row selection**: when your curation differs from what the next scan would pre-check, the confirmation sheet asks whether to keep it, and later scans pre-check exactly those rows.
- **Menu bar memory ranking**: a quit button on each running app's row, with the warning drawn the moment the pointer reaches the controls.
- **Settings**: a menu bar logo switch.
- **Lemon-style brand language**: warm palette, green call-to-action button with its press-scale response, shared hero prompt, gradient scan ring with its sweep arc, and the draw-in success mark — the welcome page and the general module's empty state now share one front-door composition.
- **Universal binary**: one download covers both Apple silicon (arm64) and Intel (x86_64) Macs, macOS 14 or later.
- **Signed and notarized**: Developer ID signature with the notarization ticket stapled — double-click to install, no Gatekeeper warning.
- **In-app updates**: earlier 1.0.x users get this release through Sparkle, no browser re-download needed.

### Under the hood

- The two cleanup features are now fully disjoint: the catch-all rules that made browser and IDE caches count twice are gone, redundant sibling rules were removed, and discovery deduplicates by path.
- General cleanup layout: the clean button sits in the page header beside the scan button, the bottom-of-page button is gone, and the scan progress title is scoped per cleanup mode.
- Menu bar panel values are drawn smaller so the panel reads more compactly; animations are one-shot or scan-bound and all honor Reduce Motion.
- Documentation and build scripts moved to English; the Chinese README was dropped in favour of the in-app language switch.
- `Scripts/build-all.sh`: one-command release pipeline (tag, build, sign, notarize, DMG, appcast, GitHub release).
