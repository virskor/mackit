## Mackit 1.0.12

Mackit now speaks Korean and Japanese, and the README comes in Traditional Chinese as well.

- **Korean and Japanese interface languages.** All 956 strings are translated in `ko` and `ja`, and Settings → General's language picker offers them by their endonyms — 한국어 and 日本語 — beside the existing Simplified Chinese, English and Traditional Chinese, following the system when set to "Follow system". Both the app and the menu bar agent declare the five localizations, so the tray agent's menu is localized too.
- **Cleaning no longer strips Korean or Japanese out of other apps.** The unused-language-pack rule keeps `ko` and `ja` per bundle the way it already kept Chinese and English: whoever runs Mackit reads at least one of the five shipped UI languages, so no other app on the machine loses its Korean or Japanese interface files.
- **READMEs in Korean, Japanese and Traditional Chinese** (`README_KO.md` / `README_JA.md` / `README_ZH_HANT.md`). Each is the full README translated with the app's own terminology — 스캔 / スキャン, 정리 / クリーンアップ, 캐시 / キャッシュ, 휴지통 / ゴミ箱 — so the documentation and the product read as one, with every command, path, identifier and URL byte-identical to the English source. All five READMEs cross-link, own language first.

### Under the hood

- The translations follow the project's placeholder and separator conventions throughout — positional `%1$@` / `%2$lld`, the unspaced `·` of the treemap tile line, the newline in the welcome message — and an independent review pass against the sources, the glossary and the call sites fixed 46 entries: dangling Japanese verb fragments, wrong particles and counters, terminology collisions such as 서비스 / サービス naming both LaunchAgents and brew services, Korean spelling and missing toast predicates.
- `LocalizationTests` now checks all five `.lproj` key sets instead of three, `AppLanguageTests` covers the new cases, and `LanguageFileScannerTests` uses genuinely foreign languages (fr / de / pt) as its removable samples plus a regression test that the five shipped UI languages survive on any system. 668 tests (+49 since 1.0.11).
